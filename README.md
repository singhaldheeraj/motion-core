# motion-core

Motion-Core is an RTOS-based embedded firmware project for STM32, designed to experiment with IMU sensor fusion and motion estimation. Features include modular algorithm implementations, real-time sensor acquisition, performance benchmarking, and motion testing to explore orientation estimation for robotics and embedded applications.
